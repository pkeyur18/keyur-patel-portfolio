The story behind the résumé

I'm a Senior Software Developer currently working at Philips as a Software Technologist 1, building software for ECG diagnostic solutions used across the US healthcare system — specifically the MCOT (Mobile Cardiac Outpatient Telemetry) and ePatch sensor platforms.
